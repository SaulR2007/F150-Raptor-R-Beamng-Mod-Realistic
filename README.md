# F150RR — Ford F-150 Raptor R (BeamNG.drive)

Realistic Ford **F-150 Raptor** pickup mod for BeamNG.drive. Vehicle folder: `vehicles/f150`. Author: **The_Gamer6000**.

Unpack / clone this repo as folder **`F150RR`** (formerly `RR_TRX`).

## About

Crew-cab Raptor built around custom jbeam (frame, body, suspension, drivetrain), Ford-style **Trail Control** UI, and **AdvanceTrac / DSE** drive modes. Powertrain is a supercharged 6.2L V8 with 10-speed SelectShift (limited and unlocked configs).

## Features

- Multiple factory-style configs: Raptor, Raptor Unlocked / Black / Code Orange, Baja, Rock Crawl, Sand Runner, Off-Road Pack, Street, Sport, Stealth, Police, tow/haul packages, work trucks, and more
- Drive-mode packs (Normal / Sport / Slippery through Sand, Baja, Rock Crawl, Tow/Haul) via DSE
- In-game **fordControl** app — Trail Control / transfer-case style UI
- Custom suspension, differentials, wheels/tires, and interactive cabin screen assets
- Hellcat-based engine/exhaust sound bank (`art/sound`)

## Install

1. Clone or download this repo.
2. Copy the **repo root** (so `vehicles/`, `lua/`, `ui/`, `scripts/`, `art/` sit at the top) into BeamNG’s unpacked mods folder as **`F150RR`**:

   ```
   %LOCALAPPDATA%\BeamNG\BeamNG.drive\<version>\mods\unpacked\F150RR\
   ```

   Example on Windows:

   ```
   C:\Users\<you>\AppData\Local\BeamNG\BeamNG.drive\current\mods\unpacked\F150RR\
   ```

   That folder should contain `vehicles/`, `lua/`, `ui/`, `art/`, `scripts/`, and this `README.md` directly — not inside another nested `F150RR` or old `RR_TRX` subfolder.

   If you previously used `...\unpacked\RR_TRX`, rename that folder to `F150RR` (or re-clone into `F150RR`).

3. Enable the mod in the game Repository / Mods menu if needed, then spawn **Ford F-150 Raptor**.
